## محتويات المستودع

| المسار | الغرض |
| --- | --- |
| `tokens/tokens.json` | المصدر المشترك للألوان والمسافات والخطوط والزوايا |
| `packages/flutter` | حزمة فلاتر: السمات والأزرار والبطاقات والحقول والتنبيهات |
| `examples/flutter` | تطبيق فلاتر قابل للتشغيل مع تبديل اللغة والمظهر |
| `packages/web` | حزمة CSS وJavaScript مستقلة عن إطار العمل |
| `examples/web` | كتالوج تفاعلي للمكونات على الويب |

## تشغيل الأمثلة

لتشغيل كتالوج الويب من جذر المستودع:

```sh
npm run generate
npm run check
npm run dev
```

افتح `http://127.0.0.1:4180/examples/web/`.

لتشغيل تطبيق فلاتر:

```sh
cd examples/flutter
flutter pub get
flutter run -d chrome
```

يوضح المثال اتجاه RTL والخط العربي. يحدد التطبيق المستهلك اللغة والترجمة واتجاه الواجهة. استخدم `BkTheme.light(arabic: true)` و`BkTheme.dark(arabic: true)` للخط العربي.

## قواعد التطوير

ابدأ بتعديل ملف الرموز ثم شغّل `npm run generate`. لا تعدّل الملفات المولدة يدوياً. حدّث المثالين والتوثيق وسجل التغييرات عند تغيير واجهة أي مكون. تتحقق GitHub Actions من تزامن الرموز وتباين الألوان وتحليل فلاتر واختباراته، ثم تنشر الكتالوجين على GitHub Pages.

المكونات مسؤولة عن العرض؛ التطبيق المستهلك مسؤول عن التحقق المحاسبي وحفظ البيانات والتحديثات والصلاحيات. أرقام الأمثلة توضيحية. الإصدار الأول للحزم هو `0.9.0` ولم يُدمج بعد في شاشات تطبيق بكرة الحالية.
