# Changelog

## 0.9.0

- Document every public component against the ten required sections in English and Arabic.
- Add 49 searchable web references and individual Markdown pages with source-derived Flutter APIs, related types, web bindings and implementation examples.
- Compile-check Flutter snippets and enforce documentation coverage/drift through CI.
- Publish the documentation standard and maintenance workflow.

## 0.8.0

- Add nine bilingual design-pattern recipes covering authentication, CRUD, search/filtering, multi-step forms, lists, dashboards, notifications, errors and permissions.
- Provide interactive local-only web flows and independent Flutter demo routes with existing design-system components.
- Add recipe model and flow regression tests; document service boundaries, recovery, accessibility and acceptance criteria.

## 0.7.0

- Define all ten component states with bilingual web and Flutter examples and a component applicability matrix.
- Add read-only and success feedback to BkTextField; errors take precedence over success.
- Align web interaction styling and prevent disabled menu, popover and modal triggers from opening.
- Add regression coverage for read-only focus/selection and validation feedback priority.

## 0.6.0

- Add all ten layout groups to web and Flutter catalogues with English/Arabic examples.
- Provide containers, flow, grid, dividers, spacers, overlays, modal/sheet helpers, responsive layouts, page scaffolds and section headers.
- Document responsive constraints, scrolling, focus, RTL and compatibility; test narrow layouts and modal routes.

## 0.5.0

- Add ten data-display groups with bilingual web and Flutter examples.
- Add controlled tables/grids, list tiles, avatar/image fallback, tags, tooltips/popovers, expansion panels, timelines, bar charts, KPI cards and no-results actions.
- Add searchable and numerically sorted sample data, accessible chart values, anchored popover focus behavior and local illustration assets.
- Test sort behavior, tag/reset actions, expansion, image failure, zero-value charts and popover dismissal.

## 0.4.0

- Add eleven navigation patterns to Flutter and web, with Arabic/English examples and all three themes.
- Add controlled destination navigation, native drawers/tabs/steppers, breadcrumbs, bounded pagination and explicit back actions.
- Add reusable web tab/menu keyboard helpers, contextual actions and listener cleanup.
- Document state ownership, routing boundaries, focus behavior and accessible interaction contracts.

## 0.3.0

- Add UI component groups: Buttons & Actions and Feedback & Status.
- Add tertiary actions, named icon buttons, wrapping button groups, toast/snackbar, progress and skeleton primitives.
- Add bilingual interactive examples, destructive confirmation previews and component state/accessibility documentation.
- Test accessible action activation, native progress semantics and toast dismissal.

## 0.2.0

- Complete all ten foundation categories with generated CSS/Dart tokens and bilingual catalogue references.
- Add secondary/accent/neutral colors, typography weights/leading/tracking, borders, shadows, shared outline icons, responsive grids and motion recipes.
